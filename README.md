# Tether Core

Tether Core is the shared foundation for the Tether package family.

Tether helps Laravel and PHP applications build offline-first experiences where local clients can keep working without a network connection and later reconcile their changes with a Laravel server.

This package provides the common language used by the client and server packages.

## Documentation

Full documentation is available at [laravel-tether.com](https://laravel-tether.com/docs).

## Other Tether packages

- [Tether Client](https://github.com/lrakauskas/tether-client): The client-side package for recording local changes and syncing them back to the server.
- [Tether Server](https://github.com/lrakauskas/tether-server): The server-side package for handling sync requests and resolving conflicts.
